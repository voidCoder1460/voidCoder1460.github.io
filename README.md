
# ◈ Immersive Portals Optimizer

**A performance-focused optimization project for Immersive Portals on Minecraft Java Edition 1.20.1 with Forge.**

Designed with Intel-powered PCs in mind, this project aims to improve FPS consistency and reduce unnecessary RAM overhead during portal-heavy gameplay.

> [!IMPORTANT]
> This project targets Minecraft 1.20.1 Forge. Actual optimization results and compatibility depend on the implementation and must be tested. No specific FPS gains or RAM reductions are guaranteed.

---

## ✨ Features

- ⚡ **FPS optimization goals** — Target unnecessary rendering and processing overhead.
- 🧠 **Memory efficiency goals** — Explore ways to reduce avoidable memory allocations and overhead.
- 🌀 **Portal-focused optimization** — Focus on the additional workload associated with Immersive Portals.
- 💻 **Intel PC focus** — Intended for testing on Intel-powered systems.
- 🔧 **Forge compatibility target** — Developed for the Minecraft 1.20.1 Forge environment.
- 📦 **Simple installation** — Intended to be installed as a JAR in the Minecraft `mods` folder.

## 🛠️ Installation

1. Install Minecraft Java Edition **1.20.1**.
2. Install a compatible Minecraft Forge version for 1.20.1.
3. Download the optimizer JAR.
4. Open your Minecraft installation or launcher profile directory.
5. Locate the `mods` folder. Create it if necessary.
6. Place `immersive-portals-optimizer-1-20-1-2.jar` inside the folder.
7. Launch Minecraft using the Forge profile.
8. Check the game logs for errors and confirm that the mod loads correctly.

### Example directory

```text
.minecraft/
└── mods/
    ├── immersive-portals-optimizer-1-20-1-2.jar
    └── other-compatible-mods.jar
```

For third-party launchers, use the `mods` folder belonging to the correct Minecraft instance.
